# PlugDock – färdiga versioner

Här ligger bara färdiga, signerade versioner av PlugDock och versionslistan
(`appcast.xml`) som PlugDock själv läser för att uppdatera sig. Ingen källkod.

Varje version är signerad med The Plug Management SL:s Developer ID, kontrollerad
(notariserad) av Apple och signerad med PlugDocks uppdateringsnyckel.
